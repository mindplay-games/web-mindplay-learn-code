# MindPlay – תרגול

מעבדת ארכיטקטורה – ממליץ הסרטים נמצאת תחת **תרגול פרויקטים – שנה ג׳**. היא מדמה בדפדפן את פרויקט Flask; האתר הסטטי אינו מריץ Python או Flask.

להרצה מקומית: `python -m http.server 4173`, ואז `http://127.0.0.1:4173/movie-lab.html`.

## מעבדת שבע השאלות

שם פרטי וקבוצה מספרית בלבד. בדיוק שבע שאלות: ארכיטקטורה, טופסי HTML, POST, request.form, JSON, סינון Python ודיבוג. התוכן והאינטראקציות עודכנו לפי [שבע השאלות המאושרות](docs/movie-lab-approved-questions.md): בחירה, השלמות קוד בלחיצה, מיון, התאמות, חקירת JSON ובחירת סרטים מרובה. כל שאלה מציגה קוד רלוונטי. נדרשת תשובה נכונה לפני התקדמות; נקודה רק בניסיון הראשון, עד 7 נקודות. כל ניסיון ותשובתו נשמרים. הסיכום מציג שבע שאלות, ניסיונות שגויים ונכונים, תשובות צפויות וניקוד.

## Google Forms

בסיום לוחצים **שליחת התוצאות למורה**. הכפתור פותח בכרטיסייה חדשה את טופס Google שסופק, עם שם, קבוצה, ציון ופירוט מלא שממולאים מהתוצאות בפועל. התלמיד חייב לבדוק וללחוץ על **שליחה בטופס Google**. פתיחת הטופס אינה אישור הגשה; האתר אינו מציג הצלחה או טוען ש־Google קיבל תשובה. אין שליחה ברקע ואין Apps Script, Sheets או Formspree בזרימה הפעילה.

[מיפוי השדות, בדיקות ומגבלות](docs/movie-lab-google-forms.md). הכתובת ומזהי השדות נמצאים ב־`js/movie-lab.js`; אין צורך בקובץ הגדרות נוסף או בקוד שרת. `google-apps-script/Code.gs` נשמר כארכיון בלבד.

## התקדמות קיימת ובדיקות

השאלות המאושרות נשמרות במפתח חדש `mindplay.movieArchitectureLab.v3.approved`. תוצאות שבע השאלות הקודמות נשארות במפתח הישן ללא שינוי; רק השם והקבוצה מוצעים מחדש, ללא העברת ציונים לתוכן אחר. שמות מלאים ישנים מצומצמים לשם פרטי ודגלי שליחה ישנים אינם מאשרים הגשת טופס. בגרסאות ששמרו רק תשובה אחרונה, תוכן ניסיונות שנדרס אינו ניתן לשחזור ומסומן כחסר; מעתה נשמרים כל הניסיונות. התוצאות נשארות בדפדפן גם לאחר פתיחת הטופס או סגירתו.

```sh
node tests/movie-submission.cjs
python tests/movie-lab-ui.py
node --check js/movie-lab.js
```

בדיקות טופס Google מדומות בלבד. לא בוצעה הגשה אמיתית ולא אומתה נגישות/תצוגת השדות בטופס החי. בדיקות דפדפן מקומיות מכסות מחשב/טאבלט/נייד, ניסיונות שגויים, ניקוד, היסטוריית תשובות, ארבעה שדות ממולאים, שמירת תוצאות וללא אישור הגשה שקרי. דפים אחרים נבדקים בבדיקות עשן.

השינויים מקומיים ב־main; אין לבצע commit, push או פרסום ללא אישור מפורש.
